取得する情報 / Data accessed

この道具は、利用者本人が許可した Google アカウントの YouTube チャンネルに対して、動画のアップロードと動画情報の更新を行うためだけに、YouTube Data API へのアクセス権を使います。

This tool uses access to the YouTube Data API only to upload videos and update video information on the YouTube channel of the Google account that the user authorized.

保存と共有 / Storage and sharing

アクセスのための鍵（トークン）は、利用者本人のコンピューターの中だけに保存します。取得した情報を第三者に提供・販売することはなく、広告にも使いません。

Access tokens are stored only on the user's own computer. No data is sold or shared with third parties, and none is used for advertising.

Google API の利用 / Google API use

Google API から受け取った情報の利用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。また Google のプライバシーポリシーが適用されます。

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The Google Privacy Policy also applies.

アクセスの取り消し / Revoking access

許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。 Access can be revoked at any time from your Google Account permissions page.
