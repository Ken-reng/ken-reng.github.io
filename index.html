YouTube自動アップロード (YouTube Auto Uploader)

YouTube自動アップロードは、開発者本人が自分の YouTube チャンネルに、自分で制作した動画をアップロードするための個人用の道具です。一般には提供していません。

YouTube Auto Uploader is a personal tool that its developer uses to upload videos they produced to their own YouTube channel. It is not offered to the public.

できること / What it does

  • 動画・サムネイル・字幕のアップロード / Uploads videos, thumbnails and captions
  • タイトル・説明・公開設定の登録 / Sets titles, descriptions and publishing status

Google の YouTube Data API を使います。This tool uses the YouTube Data API. YouTube Terms of Service
